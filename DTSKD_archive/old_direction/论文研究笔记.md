## 三、核心发现：α_t 调度问题

### 3.1 历史教师准确率监控

在 train() 中添加了 hist_acc 和 hist_entropy 监控：
- **hist_acc**：`all_predictions[input_indices]` 的 argmax 与真实标签一致率
- **hist_entropy**：`all_predictions[input_indices]` 的 Shannon 熵
- 测量时机：soft_targets 计算后、all_predictions 更新前（读到的是上轮历史值）

### 3.2 关键实验

| 实验 | α_t 调度 | 结果 |
|------|---------|------|
| 50 epoch 余弦 | 0.9→0.001（50轮衰减） | val 57%→33%，教师崩塌 |
| 50 epoch 控制 | 0.9→0.842（300轮衰减，只跑50轮） | val 稳定，教师~60%平台 |
| 50 epoch 动态 | α_t = 1 - hist_acc/100 | val 57%→54%，教师稳定60% |

### 3.3 结论

- **余弦 α_t→0 会摧毁历史教师**：α_t 过低 → 软目标无真实标签信号 → 教师自反馈退化 → 正反馈崩塌
- **动态 α_t 防止崩塌**：教师质量自动调节信任度，α_t 不会降到危险区域
- **峰值精度持平**：动态 56.9% vs 余弦 57.2%（50 epoch），但最终精度动态完胜（54.1% vs 32.8%）

## 四、代码改动清单

### adaptive_alpha 分支 vs baseline

| 改动 | 说明 |
|------|------|
| `--dynamic_alpha` | 启用动态 α_t 模式 |
| `--alpha_end_epoch` | 解耦 α_t 衰减周期与训练轮数 |
| hist_acc/hist_entropy | 训练时自动监控历史教师质量 |
| CSV 新增列 | hist_acc, hist_entropy |

### 关键公式

```
# 余弦（原版）
α_t = cos(π · epoch / end_epoch) · (cos_max - cos_min) + cos_min

# 动态 v1（当前）
α_t = 1 - last_hist_acc / 100
```
