## 二、方法：MCW-AF（边际置信度加权抗遗忘）

### 2.1 数学形式

对每个样本 $i$，在每个训练 step：

**式(1) — 边际置信度**（识别"可靠知识" vs "噪声"）：
$$m_i = p_{\text{old}}(y_i|x_i) - \max_{k \neq y_i} p_{\text{old}}(k|x_i)$$

**式(2) — 动态权重**（"抽奖机制"）：
$$w_i = \begin{cases} \exp(\alpha \cdot (m_i - \tau)), & m_i > 0 \\ 0, & m_i \leq 0 \end{cases}$$

**式(3) — 总损失**：
$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{CE+KD}} + \lambda \cdot \frac{1}{B}\sum_i w_i \cdot D_{\text{KL}}(p_i^{\text{old}} \| p_i^{\text{new}})$$

### 2.2 核心直觉

- $m_i > 0$：历史预测正确且置信 → 这是"真知识"，保护它
- $m_i \leq 0$：历史预测错误 → 这是"噪声"，不保护（$w_i = 0$）
- $\alpha$ 控制保护强度（指数放大），$\tau$ 控制保护门槛

### 2.3 v1 vs v2

| | v1（原始） | v2（改进） |
|---|---|---|
| AF 强度 | $\lambda = 0.5$ 全程恒定 | $\lambda_{\text{eff}} = 0.5 \cdot (1 - \alpha_t)$ |
| 早期 (ep 0, α_t=0.9) | $\lambda_{\text{eff}} = 0.50$ | $\lambda_{\text{eff}} = 0.05$ |
| 后期 (ep 199, α_t≈0) | $\lambda_{\text{eff}} = 0.50$ | $\lambda_{\text{eff}} = 0.50$ |
| 设计哲学 | 全程均匀保护 | 早期放手探索，后期巩固保护 |

α_t 和 AF 权重的对偶关系：
- α_t 高 → "相信 GT 标签" → 历史不可靠 → AF 应该弱 → (1-α_t) 低 ✓
- α_t 低 → "全靠历史预测" → 历史是唯一教师 → AF 应该强 → (1-α_t) 高 ✓

## 四、关键发现：有害遗忘 vs 有益去噪的分解

### 4.1 问题

MCW-AF 的整体遗忘率仅从 3.48% 降到 3.25%（相对改善 6.6%），精度还略有下降。这是否意味着方法无效？

### 4.2 方法：从 Per-Epoch Correctness 矩阵推断遗忘类型

基于 Wu et al. (ICML 2026) 的理论框架，SKD 遗忘有两种本质不同的类型：

| | 有害遗忘 (Signal Loss) | 有益去噪 (De-noising) |
|---|---|---|
| **定义** | 稳定学会的样本被遗忘 | 从未稳定学会的样本"被遗忘" |
| **对精度影响** | 负面（丢失真知识） | 正面或中性（替换噪声伪标签） |
| **应该阻止？** | ✅ 是 | ❌ 否 |

**操作化区分**（从 HistKD 的 per-epoch correctness 矩阵）：

| 特征 | 有害遗忘 (n=1061) | 有益去噪 (n=1060) |
|---|---|---|
| 最长连续正确 | **6.5 epochs** | 1.0 epochs |
| 遗忘时机 | **后期 (ep ~160)** | 早期 (ep ~76) |
| 总正确 epoch 数 | **40.1** | 5.4 |
| 振荡率 (正确↔错误翻转) | 0.23 | 0.05 |
| Harmful Score | **高** | 低 |

> Harmful Score = stability × late_forget × (1 - oscillation_rate)，以 HistKD 中位数二分

### 4.3 核心结果：MCW-AF 的选择性保护

```
HistKD 最终错误样本 (n=2121) 被分解为：
  ├── 有害遗忘 (n=1061, 50.0%):
  │     Ours v1 救回 293 个 (27.6%)  ← 强保护
  │     Ours v2 救回 352 个 (33.2%)  ← 更强
  │
  └── 有益去噪 (n=1060, 50.0%):
        Ours v1 救回  29 个 ( 2.7%)  ← 几乎不干预
        Ours v2 救回  31 个 ( 2.9%)  ← 几乎不干预

Odds Ratio (v2): 16.8x — MCW-AF 保护有害遗忘的可能性是有益去噪的 17 倍
```

**这证明了 MCW-AF 的置信度加权机制天然实现了选择性抗遗忘：**
- 高置信度 → 高稳定性 → $m_i$ 大 → $w_i$ 大 → 强保护 → 阻止信号遗忘
- 低置信度 → 高振荡 → $m_i$ 小/负 → $w_i = 0$ → 无保护 → 允许去噪继续

### 4.4 为什么选择性保护没有转化为精度优势？

**样本层面分析（v2 vs HistKD）：**

```
v2 rescued: 352 样本（从有害遗忘中救回）
v2 lost:    373 样本（HistKD 正确但 v2 错误）

净效果：-21 样本

Lost 样本特征：
  - 85% 在 epoch 20 前已与 HistKD 分道扬镳
  - 早期精度 (ep0-50): HistKD 19.5% vs v2 17.6%
  - v2 从一开始就学得更差
```

**根因：AF 的"保护"和模型的"学习"在参数层面存在竞争。**

即使 AF 只直接约束历史正确的样本（$m_i > 0$ 门控），其产生的梯度仍然改变了模型参数，间接影响了所有样本的学习。这种 **parameter interference** 是无差别的——保护样本 A 的参数更新可能损害样本 B 的学习。

**这是一个根本性的 trade-off：任何防止遗忘的约束，都会在一定程度上阻碍新知识的学习。** 在干净数据（CIFAR-100）上，300 个被救回的样本无法弥补 373 个被拖累的样本。

## 五、根因总结：为何 MCW-AF 无法超越 HistKD

### 5.1 三个层次的解释

**层次 1 — 数量不对称**
- 有害遗忘仅占最终错误样本的 50%（1061/2121）
- 被 AF 成功保护的仅占有害遗忘的 33%（352/1061）
- 被 AF 间接损害的样本占 HistKD 正确样本的 5%（373/7879）
- 净效果为负：救回 352，损失 373

**层次 2 — 时序矛盾**
- AF 需要早期弱（允许学习）后期强（防止遗忘）
- v2 通过 (1-α_t) 挂钩部分缓解了这个问题（ep100 领先 5%）
- 但后期 AF 仍然阻碍了精调（ep100→200 增长乏力）

**层次 3 — 本质冲突（更深刻的 insight）**
- SKD 中的"遗忘"大部分是去噪（有益），小部分是信号丢失（有害）
- EWC/MCW 类方法本质上是**防止预测变化**
- 但 SKD 的训练过程**需要预测变化**——因为历史预测本身在持续改进
- 阻止变化 = 阻止改进 = 精度上限降低

### 5.2 什么时候 MCW-AF 会有效？

推测 MCW-AF 在以下场景会显著优于 HistKD：

1. **标签噪声场景**：当 GT 标签不可靠时，有益去噪的需求减少，有害遗忘成为主导 → AF 的净收益变正
2. **长训练**（更少 forgetting 容忍度）：300+ epoch，模型高度收敛后微调阶段遗忘更严重
3. **小模型/低容量**：容量受限时样本间竞争更激烈，遗忘更频繁
4. **在线/持续学习场景**：数据分布变化时，旧知识的遗忘是真正的灾难性遗忘

## 七、当前结论与后续方向

### 当前结论

1. **SKD 遗忘可以分解为有害遗忘（信号丢失）和有益去噪（伪标签替换）**，操作化区分标准已建立
2. **MCW-AF 的置信度加权机制天然实现选择性保护**：17 倍倾向于保护有害遗忘而非有益去噪
3. **但在干净数据上，选择性保护无法转化为精度优势**——AF 的 parameter interference 效应拖累了更多样本
4. **SKD 中的遗忘大部分是有益去噪**（~50%），阻止它对精度有害
5. **时序反转（v2）部分有效**——早期弱 AF 帮助学习（ep100 领先 5%），但后期 AF 仍阻碍精调

## 八、标签噪声实验 (2026-06-27)

> **动机**：干净数据上 AF 无法超越 HistKD，因为 50% 的遗忘是有益去噪。增加标签噪声 → GT 不可靠 → 有益去噪需求减少 → 有害遗忘成为主导 → AF 的净收益应变正。

### 实验设计

| 实验 | 噪声 | 方法 | Best Val | 状态 |
|:-----|:---:|------|:--------:|:----:|
| `noise20_hist_s27` | 20% | HistKD | **75.57%** | ✅ |
| `noise20_ours_s27` | 20% | MCW-AF v2 | 75.46% | ✅ |

共用参数同干净实验 + `--noise_rate 0.2`，标签噪声仅污染训练集（对称翻转），验证集保持干净。

### 核心结果

| | Clean | 20% Noise |
|:--|:---:|:---:|
| HistKD Best | 79.42% | 75.57% |
| Ours v2 Best | 79.00% | 75.46% |
| **Δ (Ours − HistKD)** | **−0.42%** | **−0.11%** |
| Harmful Rescue Rate | 27.6% | **32.0%** |
| Odds Ratio (H/B) | 13.6x | 8.2x |
| Lost Samples | 363 | 471 |
| **Net Effect** | **−41** | **−12** |

- **Gap 缩小 74%**（−0.42% → −0.11%），几乎打平 — 噪声使 AF 的相对劣势大幅减少
- **有害拯救率提升**（27.6% → 32.0%）— AF 在噪声场景下保护更有力
- **Net Effect 改善 71%**（−41 → −12）但仍为负 — 20% 噪声不足以让 AF 超越 HistKD
- **有害遗忘比例未变**（50%）— 噪声并未显著改变 SKD 遗忘的构成
- **选择性下降**（Odds 13.6x → 8.2x）— 噪声使置信度信号变模糊

### 趋势解读（旧，20% 噪声后）

```
噪声率:    0%  ──────── 20% ──────── 50% (计划)
Δ Accuracy:  −0.42%    −0.11%       ？
趋势线指向：在某噪声率处 Δ 可能穿越零点 → AF 首次优于 HistKD
```

## 九、50% 标签噪声实验 (2026-06-28)

> **决定**：跳过 40%，直接拉高到 50%——若 20% Gap 已缩至 −0.11%，50% 应足够让 AF 穿越零点。

### 实验设计

| 实验 | 噪声 | 方法 | Best Val | 状态 |
|:-----|:---:|------|:--------:|:----:|
| `noise50_hist_s27` | 50% | HistKD | **65.68%** | ✅ |
| `noise50_ours_s27` | 50% | MCW-AF v2 | **66.01%** | ✅ |

共用参数同 20% 实验 + `--noise_rate 0.5`。25,000/50,000 训练标签被对称翻转。验证集保持干净。

### 核心结果

| | 0% (Clean) | 20% Noise | 50% Noise |
|:--|:--:|:--:|:--:|
| HistKD Best | 79.42% | 75.57% | 65.68% |
| Ours v2 Best | 79.00% | 75.46% | **66.01%** |
| **Δ (Ours − HistKD)** | **−0.41%** | **−0.11%** | **+0.33%** ✅ |
| Harmful Rescue Rate | 27.6% | 32.0% | **32.9%** |
| Benign Rescue Rate | 2.7% | 5.4% | 4.2% |
| Odds Ratio (H/B) | 13.6x | 8.2x | **11.2x** |
| Lost Samples | 363 | 471 | 592 |
| **Net Effect** | **−41** | **−12** | **+47** ✅ |

### 关键发现

1. **AF 首次净正收益**：Δ = +0.33%, Net = +47 — 50% 噪声下 MCW-AF 超越 HistKD
2. **有害拯救率创新高**：32.9%，比干净数据的 27.6% 提升了 19%
3. **穿越点 ~28% 噪声**：线性拟合显示 AF 在 ~28% 噪声时开始优于 HistKD
4. **选择性保持**：Odds Ratio 11.2x — 噪声使置信度信号变模糊但 AF 仍选择性保护有害遗忘
5. **50% 噪声的训练难度**：Best Val 仅 66%，vs 干净 79% — 一半标签是错的

### 训练动态观察

- **早期 (ep 0-50)**：剧烈震荡，val 在 37-46% 之间跳动——噪声导致模型在"找到信号"与"被噪声误导"间反复
- **中期 (ep 50-100)**：缓慢上升至 44-46%，Ours 与 HistKD 交错领先
- **LR Decay 1 (ep 100)**：精度跃升至 60-63%，差距缩小至 0.1% 以内
- **LR Decay 2 (ep 150)**：**关键转折**——Ours 首次拉开差距（63.52% vs 63.15%）
- **末期 (ep 150-200)**：两者继续精调，Ours 保持 0.3-0.4% 领先至终点

### AV 参数动态

| 阶段 | α_t | AF 权重 (λ × (1-α_t)) | AF Loss | 效果 |
|------|:---:|:---:|:---:|------|
| 早期 (ep 0-50) | 0.9→0.79 | 0.05→0.11 | ~0.007 | 放手探索 |
| 中期 (ep 50-100) | 0.79→0.44 | 0.11→0.28 | ~0.014 | 渐进增强 |
| LR decay 后 (ep 100-150) | 0.44→0.15 | 0.28→0.43 | ~0.047 | 强保护 |
| 末期 (ep 150-200) | 0.15→0.01 | 0.43→0.50 | ~0.031 | 巩固 |

### 最终结论

**MCW-AF 的有效性取决于标签噪声水平。** 在干净数据上 AF 的 parameter interference 拖累学习（Δ = −0.41%），但随着噪声率升高，GT 标签可靠性下降 → 有益去噪需求减少 → 有害遗忘成为主导 → AF 的保护转化为净正收益。50% 噪声下 Net Effect = +47，首次超越 HistKD（Δ = +0.33%）。穿越点位于 ~28% 噪声附近。

这证明了三个核心论点：
1. **SKD 遗忘的二元分解框架具有实际预测力**——它准确预测了 AF 在何时有用、何时有害
2. **选择性抗遗忘是可行的**——MCW-AF 在所有噪声水平下均保持 8-14x 的选择性
3. **AF 的价值在于噪声场景**——它不是一个通用改进，而是一个针对有害遗忘的精准工具

---

> **核心 insight**：MCW-AF 不是"无效"，而是在错误的方向上被评估了。它的真正价值不在于在干净数据上击败 HistKD（一个几乎不可能的目标，因为 SKD 遗忘大部分是有益的），而在于：(1) 首次提供了 SKD 遗忘的二元分解框架，(2) 证明了选择性抗遗忘是可能的，(3) 揭示了 SKD 训练中 exploration-consolidation 的根本张力，(4) 在标签噪声场景下 AF 的相对优势随噪声增加而增强。
